## 3. 审计发现

### P1：发布与内容拓扑

1. `_most_popular` 同时作为 Jekyll collection 和显式 `include` 目录发布，产生 `/most_popular/.../` 与 `/_most_popular/.../` 两套相同内容；两套 URL 均进入 sitemap，形成重复内容和错误索引面。
2. sitemap 中首页 URL 重复出现，现有审计没有校验 sitemap URL 唯一性。
3. `_documents` 中“管理诊断、组织重构、人才评估”属于遗留企业咨询内容，页面存在空章节与 “Witbacon” 旧品牌文案，且与家庭教育定位无关，却仍公开并进入 sitemap。
4. “RSS 订阅教程”仍指向 FaceReader/Witbacon 旧域名及旧外部截图，业务内容已经失效。

### P1：隐私、第三方服务与业务可信度

1. 隐私条款最后更新于 2017 年，仍声明 Google AdSense、Amazon 联盟营销和第三方广告；当前项目没有这些业务，声明与实现不一致。
2. 条款未准确列出当前使用的 Google Analytics、Disqus、Algolia、Coze、YouTube 与 CDN，也未说明用户如何避免加载可选第三方服务。
3. AI 页面直接加载第三方 beta SDK；没有用户主动触发、加载中/失败状态、降级路径或隐私提示。
4. AI SDK 的 bot ID 与脚本地址硬编码在 include 中，不便于环境迁移和维护。

### P1：产品信息架构与 UI/UX

1. 中文站点的主导航、首页 CTA、热门页、404 和条款标题大量使用英文，语言体验割裂。
2. 首页只有三张功能图，没有“从哪里开始”、最新内容或明确下一步，无法承担内容发现入口。
3. 关于页主要由大图堆叠构成，缺少服务边界、适用人群、内容路径和联系入口，图片中的文字也不利于搜索与无障碍访问。
4. 404 页面只有文字说明，没有返回首页、浏览文章或启动站内搜索的操作。
5. 页脚存在指向 `x.com`、`facebook.com` 首页的占位链接，属于低质量死入口。
6. 移动阅读工具始终显示返回顶部按钮，即使页面尚未滚动，造成视觉干扰。

### P1：搜索可靠性

1. 搜索依赖 jsDelivr、Algolia 浏览器 SDK 与远程索引；任一 CDN 或 API 失败时只写控制台错误，用户看不到可操作的失败状态。
2. 站点已经生成 `/algolia-records.json`，但未利用它作为本地只读搜索降级数据源。
3. 外部脚本动态加载没有超时、重复请求状态或清晰降级 UI。

### P2：运行时正确性和可访问性

1. 复制代码逻辑在异步 Clipboard API 尚未完成时即显示成功；失败时 UI 仍可能显示“已复制”。
2. 复制按钮和标题锚点的可见/无障碍文案固定为英文，没有随页面语言变化。
3. 移动目录关闭时仅设置 `aria-hidden`；可进一步使用 `inert`，并在打开时明确聚焦，减少辅助技术误读。
4. 移动导航缺少 Escape 关闭和外部点击关闭。
5. 搜索动态结果图片没有显式尺寸或宽高比兜底，可能在图片返回时发生布局偏移。

### P2：工程护栏

1. 生成 HTML 审计未检查页面是否具有唯一标题、唯一主标题、有效 canonical、HTTP 资源、占位域名、重复 sitemap URL 和遗留公开目录。
2. 内部链接检查只校验目标文件，不校验同页锚点是否存在。
3. CI 没有单独的 `npm audit` 与工作树生成一致性检查；当前 `site:check` 会重写压缩 JS，但不会验证生成物是否与源码一致。
4. 工程审计和实施计划此前没有保存到仓库。

## 4. 架构评价

当前静态站点架构适合内容型家庭教育网站：Jekyll 负责内容、Liquid 负责视图、少量原生脚本负责渐进增强，GitHub Pages 与 Algolia 分离部署。主要缺陷并非需要换框架，而是“发布内容边界”和“第三方失败边界”没有被明确建模。

本次应继续保持静态优先和渐进增强：

- 核心文章、分类、标签、RSS 和导航不依赖 JavaScript；
- 搜索优先使用 Algolia，失败时使用随站点发布的只读记录；
- AI 属于可选第三方能力，由用户主动加载；
- 遗留业务内容保留源文件但不再发布；
- 用生成物审计固化 SEO、隐私和可访问性边界。

## 5. 本次纳入的新功能

以下建议均适合当前产品，并纳入本次实施，而不是只停留在建议：

1. 首页“开始阅读”信息架构：主题入口、最新文章与明确 CTA。
2. Algolia 失败时的本地搜索降级。
3. AI 助手的按需加载、状态提示、失败降级和隐私说明。
4. 更可用的中文 404 恢复入口。
5. 发布物质量门禁：sitemap 唯一性、锚点、canonical、占位域名、遗留目录与基础语义检查。

## 6. 暂不引入

- 用户账号、收藏同步、付费课程、咨询预约和邮件订阅需要新的数据处理、身份、支付或运营流程，当前仓库没有相应后端和合规信息。本次不虚构这些能力。
- 不重写历史文章的观点或事实，只修复明显失效的站点级内容与入口。
- 不承诺真实浏览器视觉结果；发布后人工烟雾测试列入交付清单。
